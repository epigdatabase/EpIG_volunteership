Proposed Design

  • Prepare one reusable set of coordinate-valid records within the Neotropical boundary.
  • Display geographic distribution as rasterized point panels separated by source group.
  • Aggregate records into an equal-area hexagonal grid rather than plot 1.37 million overlapping points.
  • Use the dissolved Neotropical boundary as the mask and outline.
  • Use a logarithmic color scale for record counts.
  • Retain empty areas so sampling gaps remain visible.
  • Report the number of coordinate-valid records used and records outside the Neotropical boundary.
  • Avoid exposing individual occurrence coordinates in the rendered output.

Loading Data

The complete EpIG-DB 2.0 occurrence product is loaded locally. The raw database is employed only to prepare aggregate outputs and is not displayed in the HTML document.

Spatial Data Preparation

Spatial Layers

Three spatial inputs are prepared. the dissolved Neotropical boundary, country boundaries, and the Morrone biogeographic provinces. Invalid geometries are repaired before further spatial operations.

Table Table 1 documents the role, size, geometry status, and coordinate reference system of each spatial input. All three inputs use WGS84 (EPSG:4326).

Coordinate Screening

Longitude and latitude are converted to numeric values and evaluated sequentially. Records must have a complete coordinate pair, fall within the legal geographic ranges, and not represent the placeholder coordinate ‘(0, 0)’.

Table Table 2 shows how coordinate-valid subset was obtained. Exclusion categories are mutually exclusive within this sequence.

Projected Neotropical Dataset

Coordinate-valid records are projected to Equal Earth (EPSG:8857), filtered by the dissolved Neotropical boundary, and assigned to a 100-km equal-area hexagonal grid. Employing an equal-are projection makes the grid cells spatially comparable across the study region.

Geographic Distribution

Distribution by Data Source

The geographic distribution of coordinate-valid records was compared among four broad source groups. Separate panels were used because repositories account for most recods and would obscure less sources in a single overlaid map. All panels use the same projection, geographic extent, point size, and transparency.

Sampling Density

Spatial Aggregation

Records retained within tyhe Neotropical boundary are assigned to a 100-km hexagonal grid in the Equal Earth Projection. Interior cells are spatially comparable; cells intersecting the outer biundary are clipped for display.

Table Table 3 reports the final map denominator and verifies that all records inside the study boundary were assigned to grid cells.

Sampling Density <ap

Figure Figure 2 displays the number of records in each occupied cell. The logarithmic color transformation preserves differences across a highly differentiated count distribution. Light-grey cells represent sampled-area gaps with no retained occurrence records.

Interpretation

The map summarizes geographic sampling intensity rather than species richness or biological abundance. Cells with many records may reflect greater collection effort, or repeated sampling. Consequently, geographic differences in record density should not be interpreted directly as differences in epiphyte diversity.

Species Richness by Biogeographic Province

The province-level choropleth will represent the number of distinct formally named species recorded within each Morrone biogeographic province. Morphospecies will be evaluated separately because their identifiers may be contributor-specific.

The workflow is divided into:

  1. audit the province layer and identify its province-name field;
  2. define the records and taxonomic key used to count species;
  3. assign eligible occurrences to province polygons; 4.validate unmatched and multiple spatial assignments;
  4. calculate species richness while retaining provinces with zero records; and
  5. construct an interpret the choropleth.

Stage 1c: Check Occurrences Matches

st_intersects() returns the polygon row numbers matching each point, including boundary contacts. A point on a shared boundary may therefore match more than one province.

Stage 2: Define Records for Species Richness

Formally named species richness will be calculated from distinct cleaned scientificName values. Species, subspecies, varieties, and forms are included, following the species-level name structure established in the taxonomy audit (Section 3.2 from ExploratoryData_FR.qmd). Morphospecies and hybrids are reported separately from this count.

#| label: fig-province-richness
#| echo: false
#| fig-cap: "Observed formally named species richness across Morrone biogeographic provinces, based on coordinate-valid records within the Neotropical area."
#| fig-width: 10
#| fig-height: 8
#| fig-format: png
#| dpi: 300

# Attach the counts to the 57 named province polygons.
province_richness_map <- provinces_equal |>
  mutate(province_id = OBJECTID) |>
  filter(province_id %in% province_richness$province_id) |>
  left_join(province_richness, by = "province_id") |>
  mutate(
    # Keep the numerical zero, but display zero-richness provinces in grey.
    richness_fill = na_if(n_species, 0L)
  )

ggplot() +
  geom_sf(
    data = province_richness_map,
    aes(fill = richness_fill),
    colour = "grey45",
    linewidth = 0.15
  ) +
  geom_sf(
    data = neotropics_equal,
    fill = NA,
    colour = "black",
    linewidth = 0.4
  ) +
  scale_fill_viridis_c(
    name = "Recorded\nspecies",
    option = "viridis",
    labels = scales::label_number(big.mark = ","),
    na.value = "grey92"
  ) +
  coord_sf(
    crs = sf::st_crs(neotropics_equal),
    datum = NA,
    expand = FALSE
  ) +
  labs(
    title = "Species richness by biogeographic province",
    subtitle = "Distinct formally named species recorded in EpIG-DB",
    caption = paste0(
      "Morphospecies and hybrids are counted separately. ",
      "Grey provinces have no eligible records.\n",
      "Observed richness reflects both species occurrence and sampling effort."
    )
  ) +
  theme_void(base_size = 11) +
  theme(
    plot.title = element_text(face = "bold", size = 14),
